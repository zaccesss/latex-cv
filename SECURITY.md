# Security Policy

## Scope

This repository holds two LaTeX source files and their compiled PDFs. It runs no service and stores no data, so the attack surface is small. In scope:

- A command in either `.tex` file that could run shell commands or read files outside the project when compiled
- A compiled PDF in the repository that contains anything other than the example text

## Out of scope

- Layout or wording feedback, use a regular issue instead
- Problems in TeX Live, Tectonic or Overleaf themselves, report those to their maintainers

## Reporting a concern

> [!IMPORTANT]
> Report privately, not in a public issue. Email [contact@isaacadjei.me](mailto:contact@isaacadjei.me) with details. Expect an acknowledgement within a few days.
