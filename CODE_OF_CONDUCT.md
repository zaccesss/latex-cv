# Code of Conduct

## Standards

This repository is a LaTeX CV and cover letter shared for anyone to use. Anyone interacting with it through issues or pull requests is expected to be respectful and constructive and to give specific feedback rather than vague criticism.

## Unacceptable behaviour

Harassment, abuse or personal attacks of any kind, spam or off-topic promotion, sharing anyone's private information without consent. That includes posting a real CV with someone's contact details in an issue.

## Enforcement

> [!NOTE]
> Report unacceptable behaviour to [contact@isaacadjei.me](mailto:contact@isaacadjei.me) or via [isaacadjei.me/contact](https://isaacadjei.me/contact). Reports will be reviewed and appropriate action taken, including removing comments or blocking users if necessary.
